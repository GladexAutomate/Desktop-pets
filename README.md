# Tech Command Agent pets

Optional desktop pets for the Gladex Tech Command Agent drawer. Staff download one at a time from the app.

- `catalog.json`: the list (id, name, series, size, run direction)
- `thumbs/`: one small picture per pet
- `sheets/`: the animation sheet per pet (8 x 11 frames of 192 x 208)

Most characters are fan-made sprites of characters owned by their creators. Gladex claims no ownership. Credits to the sprite artists are in `catalog.json` (`author`). Rights holders: open an issue and the pet will be removed.
